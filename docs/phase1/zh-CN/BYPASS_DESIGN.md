# 100 L 旁路、泵与流量设计（中文读者版）

**英文工程基准：** [100 L Bypass, Pump, and Flow Design](../BYPASS_DESIGN.md)  
**用途：** 从养殖缸连续抽取很小一股代表性水样，测流量并为未来经验证的流通式传感器预留位置；它不是处理回路，也不替代缸内混合和曝气。

## 1. 设定值

| 参数 | 设计值 | 验收/报警 |
|---|---:|---|
| 缸体体积 | 名义 100 L | 记录真实工作体积。 |
| 旁路名义流量 | **80 mL/min** | 调试工作带 60–100 mL/min。 |
| 低流量 | <50 mL/min 持续 60 s | 停泵，检查堵塞、漏水、进气。 |
| 高流量 | >120 mL/min 持续 30 s | 停止/纠正，检查命令或泵复位。 |
| 内部湿体积 | 目标 ≤80 mL；硬门槛 <100 mL | 用充液质量实测，不只算几何。 |
| 80 mL/min 驻留时间 | 目标 ≤60 s | 100 mL 硬门槛对应 75 s。 |
| 大内径外部软管 | 湿段总长 ≤1.2 m | 优先缩短管路，不扩大腔体。 |
| 流量采集 | 原始 1 Hz | 每个原始值保存；仪表盘可聚合。 |

80 mL/min 时，等同 100 L 的水量约需 20.8 h 才通过旁路。这只是取样循环速度，不证明全缸已完全混匀，也不代表“一次周转”就一定有代表性。

## 2. 为什么选择蠕动泵

| 泵型 | 优点 | 主要风险 | 结论 |
|---|---|---|---|
| 蠕动泵 | 小流量控制好、可校准，液体只接触软管 | 脉动、软管/泵盒磨损 | 推荐基线 |
| 隔膜计量泵 | 可以做小流量 | 阀/膜都接液，易被生物膜/固体污染，死体积较大 | 不优先 |
| 小离心泵 | 常见 | 80 mL/min 控制差、不自吸、节流带来热和不稳定 | 拒绝作为基线 |
| 重力/虹吸 | 简单 | 随水位和污染变化，有失控虹吸风险 | 无人值守用途拒绝 |

推荐 Atlas `EZO-PMP`，但 OPEN-09 仍需正式提升。厂家范围 0.5–105 mL/min，电机 12–24 V，控制 3.3–5.5 V。泵头管是 5 mm OD × 3 mm ID PharMed BPT。

耗材寿命不是“几年免维护”：管材 >1,000 h、泵盒 1,500 h、电机 5,000 h，24/7 运行约对应 42、63、208 天。现场必须准备维护计划和备用泵盒。

`Dstart,*` 约以 105 mL/min 启动，不能保存任意 80 mL/min。恒定 80 要用 `DC,80,*`；连续模式每 20 天有内部复位，因此 Node 4 必须监督并重新发命令。

## 3. 为什么选择 SLF3S-4000B 评估套件

推荐第一台采购 `EK-SLF3S-4000B`，因为套件包含单买传感器时没有的夹具和尾线。

- ±600 mL/min 水流范围覆盖 60–100 mL/min；
- 内部体积约 58 µL；建议软管内径 5–6 mm；
- I2C 地址 `0x08`，每个字带 CRC；
- 已列明接液 PPS、316L 和环氧材料。

厂家标定液是水/异丙醇，不是本项目盐水。所以先把它作为“有没有流、趋势怎样、是否报警”的仪表，在 60/80/100 mL/min 用重量法建立带版本的盐水校正。未标定前不能把厂家水标精度直接写成虾水精度。

电气上必须走 Node 4 的 DFR0565 隔离 I2C，并把隔离输出 5 V 降到 3.3 V；详细见 [接线页](WIRING_AND_GPIO.md#8-node-4旁路泵和流量)。

## 4. 水路顺序

```text
缸内代表性中层取水点
  → 可拆粗进水护罩（≥1 mm、低死体积）
  → 短 5–6 mm ID 吸水管
  → 转接至 Atlas 泵接头
  → EZO-PMP / 3 mm ID 泵头管
  → 转回 5–6 mm ID 压力管
  → 可维护 100 目过滤器（先做污染试验，条件性）
  → 短透明竖直观察/缓脉冲段（只有需要时）
  → SLF3S-4000B，箭头指向回水方向
  → 可拆空白管段 / 未来 ≤40 mL 流通池
  → 常闭带帽取样三通，样品排废
  → 回水管
  → 固定出口，位于正常水面上方 5–10 mm，朝缸壁
```

原因：粗护罩挡虾和大颗粒，避免细滤网在吸水侧过快堵塞；泵放在分析件前以提供正向流和自吸；条件性服务过滤器放在泵后，堵塞会表现为低流量；流量计紧邻流通池上游，能记录流通池实际暴露；样品口在池后，参考取样与在线样品时间一致；小气隙防虹吸又减少瀑布式曝气。

基线不使用针阀：泵速就是流量控制，节流只会增加压力和死体积。也不默认加单向阀；只有故障分析和盐水材料复核证明需要时才加入。

## 5. 软管与接头

### 泵头段

- Atlas 泵盒管：PharMed BPT，5 mm OD × 3 mm ID，15.24 cm。
- Atlas HDPE 直通接头：软管嘴外径约 4.8 mm、通孔约 2.8 mm。
- 备用泵盒：`PMP-RC`，连续运行前现场至少一只。

### 外部主回路

- 内径 **5–6 mm**；若与 Sensirion 接头/夹具匹配，优先 6 mm。
- 材料用 PharMed BPT 或厂家明确支持浓盐水、实际温度和清洗化学品的等效品。
- 接液处禁用铜、黄铜、普通钢、成分未知的 PVC 增塑材料和天然橡胶。
- 接头可用 PP、PVDF、HDPE、PEEK 或有证据的 316L；密封材料还要核实盐度和清洗剂兼容性。
- 每个受压软管嘴都要机械夹紧；流量计用厂家夹具。

准确的公制管外径和供应商 SKU 仍要实体试配，因为泵接头与流量计接头必须同时吻合。

## 6. 湿体积预算

| 部件 | 预算 |
|---|---:|
| 1.2 m、6 mm ID 软管 | 33.9 mL |
| 泵头管 | 1.1 mL |
| SLF3S | 0.058 mL |
| 过滤器和接头 | ≤5 mL |
| 可选观察/缓脉冲段 | ≤10 mL |
| 未来/临时流通池 | ≤40 mL |
| 最坏分配合计 | **≤90.1 mL** |

90.1 mL 在 80 mL/min 下约 67.6 s。目标仍是 ≤80 mL/60 s；能省掉的观察段应省，管路应尽量缩短。硬门槛为 <100 mL 和 <75 s。

最终流通池现在不能买。Mg/Ca 探头的直径、浸入深度、方向、螺纹、流速敏感性和参比结要求未知。只能先装已测体积的可拆空白段和带帽预留口，不能猜孔位。

## 7. 泵控制状态

| 状态 | 做什么 | 何时离开/故障 |
|---|---|---|
| `SAFE_OFF` | 泵关，记录零流量 | 有操作员运行许可才继续。 |
| `PRIME` | 控制速率启动，最多 30 s | >50 mL/min 进入 `RUN`；超时进低流量故障。 |
| `RUN` | 发送/核实 `DC,80,*`，1 Hz 读原始流量 | 低/高流、I2C 丢失、漏水或维护。 |
| `RECOVER_RESET` | 复位/恢复后重新核实并发 80 指令 | 稳定 60–100 回 `RUN`，否则故障。 |
| `FAULT_LOW_FLOW` | <50 持续 60 s 后停泵并锁存报警 | 检查后人工确认重试。 |
| `FAULT_HIGH_FLOW` | >120 持续 30 s 后停止/纠正 | 查 `Dstart,*` 或校准。 |
| `MAINTENANCE` | 停泵、样品/清洗排废、所有数据标维护 | 冲洗、恢复阀帽、检漏后放行。 |

Phase 1 不实现自动加药或水质控制；Node 4 只管旁路循环和安全。

## 8. 重量法流量标定

1. 用最终软管、过滤器、空白池、高度和回水方式组装。
2. 注入记录了盐度和温度的缸水，排净气泡。
3. 确认零流量后给流量计归零。
4. 在指令 60、80、100 mL/min 各收集 10 min 到去皮容器。
5. 用该温度下可追溯的半咸水密度把质量换算体积。
6. 每点至少 3 次；可行时随机顺序。
7. 保存原始 I2C/CRC、均值、标准差、质量、时间、密度、温度、指令、泵盒寿命和标定版本。
8. 只拟合最简单且有理由的校正；达不到实验要求就报告限制，不套黑箱模型。
9. 初期每周复查，换管、泵盒、过滤器或几何后必须重做。

泵校准和流量计校准是两回事；其中一个准确不能证明另一个准确。

## 9. 代表性与维护

正式使用前做空间研究：在顶部/中层/底部、曝气/取水/回水近远处比较 DO、温度、pH/EC、盐度；同步比较旁路取样口和取水位置抓样；泵开/关各测一次，确认回水没有不允许的曝气或混合影响。

初始维护：每天看回水、漏水、气泡、折管、过滤负载和趋势；每周做重量法抽查；约 30 天检查并很可能预防性换泵管/泵盒；泵管不晚于 1,000 h、泵盒不晚于 1,500 h。任何湿路变化后都要检漏、测体积、排气和三点重标定。

清洗前后水都排废，不能回缸。

## 10. 验收

- [ ] 24 h 无漏水，电子件和接液盘干燥。
- [ ] 现场扬程下 ≤30 s 自吸。
- [ ] 三点重量法达到实验精度要求。
- [ ] 实测湿体积 <100 mL，目标 ≤80 mL。
- [ ] 夹住进水管能触发低流量停泵并保留原始数据/报警。
- [ ] 高流量/复位被检测，Node 4 恢复 80 mL/min。
- [ ] 泵、Node 4、路由器、Pi 断电后安全恢复且审计轨迹完整。
- [ ] 过滤器污染可见，不会静默偏低。
- [ ] 泵开/关空间研究没有不可接受的 DO/盐度扰动。
- [ ] 样品或清洗废液不可能误回缸。
- [ ] 最终流通池继续 HOLD，直到探头型号和几何获批。

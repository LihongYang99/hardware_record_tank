ABOUT THIS SYSTEM

What you are looking at

A lab-scale prototype of a real-time water-quality monitoring platform for Pacific white shrimp (Litopenaeus vannamei) research. Each sensor node reads its probes every 4 seconds and sends every raw log line over the lab Wi-Fi using MQTT. An NVIDIA Jetson Orin stores each record in a local database, acknowledges it only after it is saved, and serves this page. The camera is wired to the lab router and streamed over RTSP.

Sensor → ESP32 → Wi-Fi / MQTT → Jetson database → this page

Data-integrity rules: raw sensor replies are kept unchanged; missing or invalid readings are never replaced with zero; every record carries a quality-control (QC) flag and sequence number, so gaps can be detected. This is a bench setup: probes are not yet calibrated, and node clocks are not yet synchronised to UTC, so values are shown for demonstration and should not be read as validated water-quality results.

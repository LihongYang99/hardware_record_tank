# camera_node — 水下 PoE IP 相机

已根据用户提供的两个商品链接补充 Barlus 相机（商品型号 IPC5MPIP68IR42POE-B）和 TP-Link/Omada POE150S 注入器参数。实物标签、相机 IP 和视频流仍待验证。

# Node-6 — 接线与供电

与 Node-1 的一路探头相同的接法（见 [Node-1/WIRING.md](../Node-1/WIRING.md)）。**改线前先拔 ESP32 的 USB 和探头的 12 V。**

| 连接 | 接到 | 状态 |
|---|---|---|
| ESP32 GPIO17（UART1 TX） | 转换器 RXD | 用户 2026-09-29 确认 |
| ESP32 GPIO18（UART1 RX） | 转换器 TXD | 用户 2026-09-29 确认 |
| ESP32 3V3 / GND | 转换器 VCC / GND | 按 Node-1 做法，未逐根核对 |
| 探头 黄 / 蓝 | 转换器 A / B | 按 Node-1 做法，未逐根核对 |
| 探头 棕 / 黑 | 12 V + / − | 按 Node-1 做法，未逐根核对 |

- 12 V 只接探头，不接 ESP32。
- 如果烧录后一直 `TIMEOUT`：先查 A/B 是否接反、12 V 是否有电、转换器是否上电；Node-1 的 ORP 曾经因为转换器接触不良超时，重接后恢复。
